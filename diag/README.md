# 진단 녹화 올리는 곳

표적 앱 › 설정 모드 › 진단 › **진단 녹화 12초** 로 만든 파일 두 개를 여기에 올려 주세요.

- `laser-diag-lane1-날짜-시각.mp4` (카메라 영상, 모든 프레임)
- `laser-diag-lane1-날짜-시각-log.txt` (앱이 프레임마다 본 것)

올리는 법: 이 폴더에서 **Add file › Upload files** → 두 파일을 끌어 넣기 → **Commit changes**.
녹화하면서 어디를 몇 발 쐈는지(예: 검정 3발, 흰 곳 2발, 쏘지 않았는데 잡힌 것)를 커밋 메시지에 적어 주면 분석이 빨라요.

컴퓨터에서 분석: `python3 tests/replay.py diag/<파일>.mp4` (영상을 한 장씩 꺼내 같은 판정 코드로 다시 돌립니다).
